## Why IAM fixes are not automatic

Deleting a user or detaching a policy can take down a production workload, and a real attacker-created admin should trigger incident response (preserve evidence, find what the credentials touched) rather than a silent cleanup. Palisade raises those findings as high severity and emits the exact remediation commands for a human to run.
